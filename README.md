# Resume Agent

An AI agent project for tailoring resumes, improving bullet points, matching job descriptions, and preparing application materials.

## Goals

- Tailor a master resume to a specific role
- Preserve factual accuracy and avoid invented experience
- Improve clarity, impact, and ATS compatibility
- Produce concise interview-preparation notes

## Project structure

```text
resume-agent/
├── prompts/       Agent instructions and reusable prompts
├── examples/      Sample inputs and outputs
├── src/           Application source code
└── tests/         Automated tests
```
